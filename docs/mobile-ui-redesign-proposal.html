Esponal 移动端 UI 重构与任务流方案

定位：以「视频 + 阅读」泛听泛读为主，将「导入书架」并入阅读，为「复习 / 词库」收口资产，把「听力播客 / 语音对话 Robot / 语法 / 发音」做成轻量快捷工具区。

1. 底部 5 Tab 与页面归属重组 结构瘦身

Tab 现状问题 改版后职责（唯一入口，不再多处重复）
首页 9 个平级长列表 + 统计图，与「我的」大量重复 每日出发台：继续看/读（1~2 张）+ 待复习轻提醒 + 4 格工具快捷区（听力精听、语音对话、语法、字母发音）+ 搜视频
视频 仅频道列表与搜视频入口 泛听泛视主阵地：顶部搜索 + 频道/近期更新 + 继续观看进度条 + 双语字幕点词查词
阅读 只有 AI 短文，导入库藏在「我的」最深处 双切换「精选短文 / 我的书架」：精选短文接入真实西语媒体（如 RFI/BBC Mundo 爬虫）；我的书架承接 EPUB/PDF 阅读
复习 只放 FSRS 刷卡，词库/短语却藏在「我的」 记忆与词库中心：顶部切换「今日卡片 / 我的词库 / 短语搭配」，查词收藏后直接在这里巩固
我的 塞了 8 个业务入口 + 6 个设置项，像杂物间 纯粹个人中心：账号与积分、我的下载（离线 PDF）、发音/缓存设置、检查更新、退出登录

2. 任务流串联：轻量闭环，不加打卡压力 核心体验

视频 / 播客 / 西媒阅读 / 书架
→
点词查词（含动词时态变位）
→
复习 Tab（卡片 + 词库/搭配）
→
语音 Robot / 精听巩固
  • 首页不逼用户打卡：首页顶部只给一个温和的「接着学」主卡（如果正在看视频/读书，优先恢复；有待复习时用副按钮提示“顺便过 12 个词”）。
  • 复习批末自然衔接输出：刷完一组 FSRS 卡片后，小结页底部给一个轻入口：「用刚复习的词和 AI 聊 2 分钟」直接带出关键词进入语音对话。

3. 三个重点模块的内容与交互升级方案 内容与 AI

模块 可行技术方案 为什么这样选
听力精听
Podcast 接入		 后端配置精选西语播客 RSS 源（如 Notes in Spanish、Español con Juan、RFI Español 音频节目），抓取真实 MP3 音频 URL 与标题，并按 30 秒片段做精听切片 + 转写对照；Spotify 链接可作为外部播客发现补充。 Spotify Web API 出于版权限制，不提供完整 MP3 音频流（仅 30 秒 preview），无法直接做精听切片；而公开 Podcast RSS 本身就是标准直链 MP3，稳定合法且可做 30s 精听+字幕对齐。
阅读精选
西媒爬虫		 服务端定时任务（Cron / 手动触发）抓取 RFI 西语之声、BBC Mundo、20 Minutos 等公开 RSS，抽取正文并做段落清洗，自动标注 A1-B1 难度与中文导读，存入数据库供 Web 与移动端阅读。 比纯 AI 生成更地道、有时效性；复用现有阅读器点击查词与动词变位能力，真正实现“读真实西语新闻”。
口语 Robot
语音直聊		 从“文字聊天框”改为 Voice-first 通话界面：大麦克风按钮按住/点击说话 → 录音上传 → Whisper 转写 → AI 角色生成简短西语回复（带中文提示折叠）→ 自动语音播报，形成连续对话流。 移动端场景下打字练口语太重，语音输入 + 自动 TTS 播报才真正接近“和西语 Robot 直接对话”的体验。
