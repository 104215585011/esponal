结构规则(模拟背后只有这三层,三种动效)

tab · 淡入

5 个一级页活在同一个 layout 里,壳只渲染一次。切 tab 时只有内容区换,底栏不动、不闪、不位移,过渡 120–150ms 淡入,不做横向滑动。

push · 右滑入

播放页、阅读器、积分、会员是覆盖层:底栏隐藏,顶栏变成"返回箭头 + 标题",250ms 右滑入。深链直达时返回箭头回它所属的 tab。

sheet · 上滑

查词、导入、选页从底部上来,250ms;下拉 / 点遮罩 / 系统返回都是关 sheet,不退出页面。查词绝不跳页 —— 一跳页就丢了刚读的那句。

回退四条:tab 页无返回箭头(Android 物理返回:非首页 → 回首页);push 页箭头 = back(),无历史则回所属 tab;sheet 的返回只关 sheet;流程完成态的按钮清栈回起点,按返回不能穿回中间页。
