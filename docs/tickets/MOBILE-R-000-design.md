## 二、App 壳规范(Shell)

### 结构
- **壳 = 底部 tab 栏 + 顶栏 + 页面容器**,只渲染一次,tab 间切换不重建壳。
- **两类页面**:
  - **tab 页**(5 个):活在壳内,无返回箭头;
  - **推入页**(详情级:watch 播放、阅读器、导入阅读、积分账户、会员、设置、课程日、语料库详情…):覆盖在壳上滑入,**顶栏=返回箭头+标题**,底部 tab 栏隐藏(沉浸)。
- **第三类:sheet**(查词卡、导入输入、选页器):底部上滑,拖拽/下滑关闭。

### 过渡(全站只许三种)
| 类型 | 动效 | 时长 |
|---|---|---|
| tab 切换 | 无滑动,内容淡入 | ≤150ms |
| 推入页 | 右侧滑入;返回左滑出 | 250ms |
| sheet | 底部上滑;下拉关闭 | 250ms |

### 壳层统一处理
- 安全区(env(safe-area-inset));tab 页**滚动位置记忆**(切走再回不丢);单 player 约束在壳层保证(推入 watch 时暂停他处播放);字体/token 沿用 `MOBILE-design-language.md`。

## 三、回退规则(Back Model,四条治"回退混乱")
1. **tab 页**:无返回箭头。Android 系统返回:非首页 tab → 回首页;首页 → 退出 App(双击确认可后加)。
2. **推入页**:返回箭头 = `router.back()`;**深链直达**(无历史)时回退到其**所属 tab**(watch→视频,阅读器→阅读,积分/会员→我的)。每个推入页在路由表里声明所属 tab。
3. **sheet**:下拉/点遮罩/系统返回 = 关闭 sheet(不退页面)。
4. **流程完成**:完成态页的"完成"按钮 = 显式导航回流程起点 tab,**清掉中间栈**(不许返回键穿回表单/支付中间页)。

## 四、流程闭合图(核心五条,每条必须有完成态+去向)
| 流程 | 路径 | 完成态 → 去向 |
|---|---|---|
| 看视频 | 首页/视频 → watch(推入)→ 查词(sheet)→ 收藏 toast"已加入生词本" | 返回 → 原 tab,首页"继续学习"卡已更新 |
| 阅读 | 阅读 → 读物(推入)→ 查词/收藏 → 退出自动记进度 | 返回 → 书架卡显示进度%;读完显"已读完 ✅" |
| 导入 | 任意页 `+` → Popover → sheet(传/贴链接)→ 上传进度条 → **toast"导入成功"** | 文件→跳转阅读 tab 书架(新卡高亮);链接→直接推入 watch |
| 复习 | 首页"待复习 N"/复习 tab → 复习流(推入)→ 逐词 → **完成页"今日复习完成 ✅ N 词"** | 按钮"回首页",首页待复习卡变 ✅ |
| 积分/会员 | 我的 → 积分账户(推入)→ 明细/消耗说明;配额不足内联 → 会员(推入)→ 购买 | 购买成功页 → "返回"清栈回·我的,余额即时刷新 |
