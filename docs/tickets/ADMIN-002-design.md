# ADMIN-002 管理后台 · 2026-11-18 10:58

PC 使用现有品牌文字、表格和表单样式。在 /admin 提供用量、用户、操作记录三个入口。用量按供应商和功能展示今日与本月，服务可登记额度和周期。用户用邮箱搜索，详情提供积分、会员与权限调整，保存前填写原因。

Android 在设置页追加管理分组。用量、用户和操作记录用原生弹窗呈现，完整后台链接打开 /admin。服务端核验单一管理员账号，两端共用接口。

实现顺序为新增用量和审计数据、接入供应商及功能限额、建立 PC 页面、接入 Android 设置。验证匿名和普通用户拒绝、积分调整与流水同事务、每日限额、调用统计、双端入口。
