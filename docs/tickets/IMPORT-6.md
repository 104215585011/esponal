# IMPORT-6 — 阅读器体验升级(真·阅读器)【设计:Claude1 · 实现:Codex1】

**优先级**:P1 · **依赖**:IMPORT-5(EPUB 含图 HTML 章节)完成后接
**设计模型**:`docs/tickets/IMPORT-6-mockup.html`(待用户批准后实现)
**适用**:`/import/[id]` 阅读器(EPUB + PDF);lectura 平台读物后续按同套升级(单列票)

## 用户需求(2026-06-11 原话)
翻页特效、字体大小样式、纸张底色样式,"做的像个真的阅读器一样";EPUB/PDF 布局和大小有问题;**EPUB 没有分页 → 需要我们自己分页**,把流式内容隔成一页一页。

## 设计决策(PM 定)

### 1. EPUB 自分页(核心)
- **CSS 多栏分页法**(业界标准做法):章节 HTML 容器设 `column-width = 视口宽`,内容自动流成横向一栏=一页;`总页数 = ceil(scrollWidth / 页宽)`;翻页 = 横向位移一页宽。
- **字号/行距/字体一变 → 重排重算页数**,并把当前阅读位置锚定回最近段落(记录页首元素,重排后 scrollIntoView 对齐),不许跳丢位置。
- 进度格式升级:`epub:<chapterIdx>:<pageInChapter>`(兼容旧 `epub:<idx>` 迁移);全书进度条 = 章节权重近似即可。
- 图片约束 `max-width:100%; max-height:90vh`,避免插图把列撑爆。

### 2. PDF 布局修正
- **fit-width 为默认**:按视口宽 × devicePixelRatio 渲染(当前模糊/大小问题多半是没乘 DPR 或 scale 固定),页面居中、页间留缝;
- 翻页改为与 EPUB 一致的**横向单页滑动**(一屏一页),保持两格式手感统一;
- 双击放大/捏合缩放 = v2,本票不做。

### 3. 翻页特效
- **两档:滑动(默认)/ 无动画**。滑动 = 250ms transform(与壳的推入过渡同曲线),支持手势拖动跟手 + 点击左/右 1/4 屏翻页。
- **不做仿真卷页**(WebView 性能差、收益低,明确排除)。

### 4. 阅读设置面板(底部控制条 Aa 唤起,bottom-sheet)
| 设置 | 档位 | 默认 |
|---|---|---|
| 字号 | 5 档步进(15–23px) | 17px |
| 行距 | 紧/标准/松 | 标准 |
| 字体 | 无衬线(现有 Noto/Jakarta)/ **衬线(西文 Literata 或 Source Serif + 中文 Noto Serif SC)** | 无衬线 |
| **纸张底色** | **纯白 / 米黄(护眼)/ 夜间(深灰底浅字)** | 纯白 |
| 翻页 | 滑动 / 无动画 | 滑动 |
- 设置**持久化**(localStorage,全书共用);夜间只作用于阅读器内部(不动全站主题);EPUB/PDF 共用同一面板(PDF 的字号/字体/行距项置灰,底色对 PDF = 页面周围底色 + canvas 滤镜不做)。

### 5. 阅读器外壳(沉浸)
- 进入即沉浸:顶栏/底部控制条默认显示,**点击页面中央 1/2 区域切换显隐**;左右 1/4 区域 = 翻页热区。
- 底部控制条:**Aa / 目录 / ◀ 12/300 ▶**(点页码弹滑块跳页)。**无连续朗读键**(决策见 §6);目录=EPUB 章节列表 sheet,PDF 仅滑块。
- 查词:点词逻辑不变(LookupCardStack);翻页手势与点词不冲突(拖动阈值区分)。

### 6. 整句朗读(方案 C,2026-06-11 用户定:只读所点句,不做连续朗读)
- **交互**:点词 → 查词卡(现有)内加按钮 **「🔊 朗读整句 ⚡0.1」**(FE-003 计费标记风格);词自身发音按钮照旧。零新手势,无误触。
- **句子切分**:
  - EPUB:章节 HTML 渲染前逐句包裹 `<span data-sent="i">`(西语句界正则:`.!?…` + 配对 `¿¡` + 后接空白+大写/数字;缩写黑名单 Sr./Sra./Dr./etc. 防误切)。行内 span 不影响多栏分页。点词 → closest(`[data-sent]`) 得所在句。
  - PDF:文字层 item 按阅读序拼页文本 → 同一套句界切分 → 记录"句 i = item a..b" 映射;点 item → 区间查找得整句。
- **播放/扣费**:句文本走**现有 `/api/tts`**(按次 0.1 + 流水,复用);**缓存命中不扣**(tts 按文本 hash 缓存音频——Codex 确认现有路由行为,若命中仍扣需改为命中免);阅读器内单 Audio 实例(再点切换、翻页即停);播放中**整句高亮**(brand-soft),播完清除。
